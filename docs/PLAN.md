# 开发计划

> 上游：市场分析见 `deepseek-fin-harness/pod/docs/reposition/11-market-feature-analysis.md`。
> 本计划只做一件事：**把"agent 权限审计交付物"变成可重复、可收费的产品。**

## 目标客户与收费方式

- **买家**：给企业做 AI 落地的小乙方 / 工作室 / 独立顾问——他签合同时会被问
  "这个 agent 能碰什么、做过什么"，答不上来就丢单或被迫降价。
- **形态**：一次性交付物，$1,500–8,000 / 次（覆盖 2–5 台机器），不做年费订阅
  （证据：只有 36% 的组织有专门 AI 安全预算，33% 是逐案批钱）。
- **交付三样**：报告 + 权限收敛策略 + **收货方能自己验的链接**。

### 明确不做

## 验收与杀线

| 时点 | 指标 | 未达成则 |
|---|---|---|
| 30 天 | 5 次真实交付、3 次有人真的点开验证链接、1 个付费 | 换买家（从"乙方"换成"自己要过合规的出海团队"） |
| 60 天 | 0 付费 | 把引擎拆成开源组件，放弃商业化 |

**更细的证伪信号**：对方收下报告但从不点验证链接 → 说明"可验证"不是他付钱的原因，
改卖"帮你把权限收紧"，别卖证据。
