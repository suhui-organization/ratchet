# 发布手册（第一轮社交）

> 素材在 [01-scan-report.en.md](01-scan-report.en.md)（发现帖）与
> [03-tool-surface.en.md](03-tool-surface.en.md)（工具面帖）。
> 这份手册只解决一件事：**谁、在哪个网址、贴哪一段、什么时候贴、贴完两小时做什么**。
>
> 顺序不能颠倒：目录先铺（已完成），社交后发。反过来会出现"点进来装不上"。

---

## 0. 发之前必须先确认的三件事

1. **账号存在吗、用户名是什么。** 登录页要的是用户名，不是邮箱——这是目前唯一卡住的输入。
2. **密码别用聊天里那个。** 那个字符串已经以明文出现在对话记录里，如果它同时是邮箱密码，
   风险不止社交账号。建议：先改成一个只在密码管理器里的新密码，再发帖。
3. **谁的名义。** 下面每一条都以你的 ID 发出，是公开且带署名的动作。我不想在你不知情的情况下
   替你说话——所以确认一句"这条发"我就发。

---

## 1. Reddit — r/mcp（最优先，受众最准）

| 项 | 内容 |
|---|---|
| 账号 | 需要你的 Reddit 用户名（r/mcp 允许 self post，但对新账号有 karma/年龄门槛） |
| 网址 | https://www.reddit.com/r/mcp/submit |
| 贴什么 | `03-tool-surface.en.md` 的 "Reddit — r/mcp" 段（原标题 + 正文） |
| 纪律 | **不带链接**。被问"是不是你的工具"就直接承认，并给仓库地址 |
| 时机 | 美东周二至周四 上午 9–11 点 |
| 前两小时 | 每条评论都回；有人贴自己的数字就追问细节 |

## 2. Hacker News — Show HN

| 项 | 内容 |
|---|---|
| 账号 | 需要 HN 用户名（新账号发链接会被自动降权，越老的号越稳） |
| 网址 | https://news.ycombinator.com/submit |
| 贴什么 | `01-scan-report.en.md` 的 "Show HN" 段；标题用 `Show HN: <一句事实>` |
| 纪律 | 第一段就承认做不到什么；**链接放第一条回复**，不放在正文 |
| 时机 | 美东周二至周四 上午 8–10 点（对应北京时间 20:00–22:00） |
| 前两小时 | 守评论区；有人质疑就贴可复现命令，不辩论 |

## 3. dev.to（吃 SEO 长尾，可自动化）

| 项 | 内容 |
|---|---|
| 账号 | 有 **API key** 就能发（Settings → Extensions → DEV API Keys），不需要用户名密码 |
| 贴什么 | `04-answer-the-question.en.md` 的 "dev.to / 博客（长文骨架）"，展开成正文 |
| 关键 | 末尾加 `canonical_url: https://podcloud.dlszjr.com`，否则 SEO 会把权重给 dev.to |
| 时机 | 随时；这一条不靠瞬时流量 |

## 4. X / Twitter

| 项 | 内容 |
|---|---|
| 账号 | 需要用户名（X 登录常触发验证码/二次验证，自动化最容易在这里失败） |
| 贴什么 | `01-scan-report.en.md` 的 X 线程（1/ 到 5/ 逐条发） |
| 纪律 | 链接放**第一条回复**；只写数字与机制，不写"安全" |
| 时机 | 与 Reddit 同一天，但错开 2 小时 |

## 5. Mastodon — infosec.exchange

| 项 | 内容 |
|---|---|
| 账号 | 该实例需要申请通过，未必已有号 |
| 贴什么 | 短结论 + 站点链接（这个平台**不降权外链**） |
| 时机 | 随时 |

## 6. 发完之后盯什么（这才是重点）

| 信号 | 含义 | 动作 |
|---|---|---|
| 有人贴自己的 server/未锁版本数 | 内容有效 | 追问细节，别急着推产品 |
| 有人问"怎么装" | 漏斗通 | 给 README 首屏那条命令 |
| 有人问"这跟 Snyk 有什么区别" | 定位没讲清 | 用 Playbook §8 的答案，一句话说完 |
| 只有赞没有安装 | 内容好看但没痛点 | 换选题：改发"客户问起我怎么答" |
| 有人报误判 | 这就是反馈的入口 | 让他贴 `ratchet scan` 输出，开 issue |

**两周内要看的三个数**（不是 star）：定价页 checkout 打开次数、`scan` 之后继续跑
`policy draft` 的人、第一个付费单。60 天 0 付费 → 按 [GTM.md](../GTM.md) 的止损线停。
