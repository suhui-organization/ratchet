Ratchet 控制面（server）…

连接中 凭据 – 事件链 – 断流 – 遏制 –

这一页由控制面自己提供：台账、复算验证、跨次比对、遏制记录、触达查询。 Agent 侧的工具是 ratchet CLI 与传感器（跑在被管的机器上，只读观测）； 收货方用验证页或离线验证器，不需要连这里。术语见 docs/ROLES.md。

这不是防火墙。它解决的是另一个问题：当客户、审计或甲方问"这些 agent 到底被允许碰什么、 你凭什么这么说"时，你现在交得出东西：一份别人不用信你就能自己验的凭据。 拦截不在这条路上（Agent 侧只读），原因见 docs/ROLES.md。

这份服务没有任何认证。能连上它就能读全部台账、伪造凭据、触发遏制。 只在本机或内网使用，不要暴露到公网。
把这台机器接进来（两步，命令直接复制）
  1. 在被管的那台机器上产出一份凭据（需要 ratchet，装法见 GitHub Release）： ratchet deliver --out /tmp/v --home "$HOME" --report-cmd "python3 -m ratchet_service.cli"

    这一步完全离线也能跑：读本机真实配置，产出策略 + 报告 + 凭据 + 证据哈希。

  2. 把它交给控制面（地址已按当前页面填好）：

    控制面会用和 CLI 同一份规则复算一遍。想连证据一起交（它才能重算哈希）： 用传感器，或见 docs/VERIFY-LOCAL.md。

只想让人验、不想要台账？把 /tmp/v/delivery 整个交给收货方， 或让他拖进验证页；那条路完全不经过这里，也不需要装任何东西。

台账里出现过的资产会列在上面；按 / 可直接聚焦输入框。
